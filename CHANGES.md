# CHANGES — what was fixed after testing (Animashaun Adeola, 2026/A/MIT/0432)

The first version was drafted by an AI assistant. Claude then ran every script
the way a GitHub Codespace runs them: Ubuntu 24.04, PostgreSQL 16 in
`/etc/postgresql/16/main`, MongoDB 8, and a `codespace` user who may only `sudo`
as root. Below is every problem found when the scripts were run, and the fix.
Final test: `setup.sh` and then P1 → P5 ran from a clean database with no
errors in about 35 seconds after setup. P3 and P5 were also run a second time
to check that re-running works.
